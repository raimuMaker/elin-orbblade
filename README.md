# Orbblade — 魔法剣の型

Elin向けの開発中MODです。拾った素材から属性オーブを作って剣に装着し、剣を使い込んでキャラが属性ごとの「型」を覚えます。

## 遊び方の予定

1. 拾った素材から炎のオーブを作り、剣に装着する。
2. オーブを装着した剣の通常攻撃を当てると、火炎の追加効果が発動し、キャラの炎の習熟度が上がる。
3. 習熟度が一定に達すると「炎の型・踏み込み斬り」を習得する。炎のオーブ付きの剣を装備中に、スタミナを消費して使える。

装着状態は剣ごと、習熟度はキャラと属性ごとに保存する予定です。使い慣れた炎の型は、別の剣に炎のオーブを装着しても使えます。

## フェーズ2の実装状況

炎のオーブの登録、所持品メニューでの作成・装着・取り外しを実装。ローカルのElin DLLを参照したビルドは警告0・エラー0。ゲーム内動作とセーブ復元は未検証。

暫定レシピは同じスタックの石5個。石の右クリックメニューから作成し、所持する剣のメニューから装着する。装着対象は単品の剣（カテゴリ sword / longsword）。オーブの取り外しには所持品の空きが必要。装着済みの剣はスタックを防止する。オーブの外見は石を流用。取り外し時は通常状態の新しい炎のオーブを返すため、オーブ固有の素材・祝福などの変更は引き継がれない。

作業台のRecipe登録、専用画像、火炎ダメージ、専用技は後続作業。現時点の導入は開発用で、ゲーム内検証は完了していない。

## フェーズ3 — 火炎追加の実装

プレイヤーの通常近接攻撃で、実際に使用した剣に炎オーブが付いている命中を記録する。ActMelee.Perform全体が正常終了した後、護符などのバニラ処理を終えて生存している相手へ、命中１回ごとに基礎3の火炎ダメージを与える暫定設定。二刀流は武器ごと、追撃は命中ごとに判定する。専用技・反撃の別アクション、投擲、遠隔攻撃は対象外。Card.DamageHPの火炎属性処理と標準エフェクトを使用する。専用の炎の軌跡は未実装。

ゲームDLL参照のReleaseビルドは警告0・エラー0。tests/CombatChecks は実装ファイルをゲーム型の代替で実行し、適用の遅延、空振り、片手だけの装着、例外後の状態復元、死亡対象、別アクション、投擲・遠隔の除外を確認した。ゲーム起動、Harmony実適用、実際の火炎耐性・護符・追撃・受け流しは未検証。タスク03の実機完了条件は残っている。テスト実行は dotnet run --project tests/CombatChecks -c Release。
