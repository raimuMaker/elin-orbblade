# Orbblade — 魔法剣の型

Elin向けの開発中MODです。拾った素材から属性オーブを作って剣に装着し、剣を使い込んでキャラが属性ごとの「型」を覚えます。

## 遊び方の予定

1. 拾った素材から炎のオーブを作り、剣に装着する。
2. オーブを装着した剣の通常攻撃を当てると、火炎の追加効果が発動し、キャラの炎の習熟度が上がる。
3. 習熟度が一定に達すると「炎の型・踏み込み斬り」を習得する。炎のオーブ付きの剣を装備中に、スタミナを消費して使える。

装着状態は剣ごと、習熟度はキャラと属性ごとに保存する予定です。使い慣れた炎の型は、別の剣に炎のオーブを装着しても使えます。

## 開発状況

現在は計画段階です。初版は炎１属性と専用技１つを対象とし、Elin安定版でクラフトから技の解放まで確認します。対象バージョンと導入手順は実機検証後に記載します。
